Drop local reward images here. Any `image_url` in rewards_catalog.csv that is NOT a full http(s):// URL is treated as a bare filename and resolved against this folder.

Example:
  rewards_catalog.csv row:  rw-golgappe,...,group-bombay-chat-food-includes-golgappapanipuri-shutterstock_1422412163.jpg,...
  Expected file:            reward-images/group-bombay-chat-food-includes-golgappapanipuri-shutterstock_1422412163.jpg

Missing files render the tier emoji instead.
